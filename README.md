# Personal Finance Analytics

## Project Overview

Personal Finance Analytics is a data analytics project focused on understanding personal financial patterns through income, expenses, savings, financial stress, debt, and other financial indicators.

The project uses Python, Pandas, and Tableau to analyze financial data, identify meaningful patterns, and communicate insights through visualizations.

## Project Objective

The objective of this project is to analyze personal finance data and identify patterns in income, expenses, savings, financial stress, debt, and financial goals.

The analysis aims to demonstrate how data analytics tools can be used to understand financial behavior and generate meaningful insights from structured financial data.

## Analysis Performed

The project includes analysis of:

* Income vs. actual savings
* Expenses vs. actual savings
* Discretionary spending vs. financial stress
* Debt-to-income ratio vs. financial stress
* Income type vs. savings goal achievement
* Financial scenario vs. actual savings
* Emergency fund vs. financial stress
* Subscription services vs. savings
* Cash flow status vs. savings goal achievement
* Fraud rate by expense category
* Category-wise average expenses

## Key Insights

* Monthly income showed a strong positive relationship with actual savings, with a correlation of **0.741**.
* Monthly expenses showed a moderate negative relationship with actual savings, with a correlation of **-0.600**.
* Discretionary spending showed relatively similar averages across financial-stress levels.
* Debt-to-income ratios showed only small differences across financial-stress groups.
* Freelance records had the highest observed savings-goal achievement rate among the analyzed income types.
* Average savings were highest under Normal conditions and lowest under Recession conditions.
* Subscription services did not show a consistent relationship with actual savings.
* No clear relationship was observed between cash-flow status and savings-goal achievement.
* Groceries had the highest observed fraud rate among the analyzed categories.
* Average expenses were relatively similar across the different expense categories.
